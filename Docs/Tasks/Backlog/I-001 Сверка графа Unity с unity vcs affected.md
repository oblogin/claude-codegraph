# I-001 Сверка графа Unity с unity vcs affected

> **Что:** на нашем Unity-проекте с закрытым редактором выполнить `unity vcs affected`, `vcs diff` и `vcs blame` с `--format json` и сравнить с нашим графом сцен и префабов.
> **Зачем:** официальный CLI может служить эталоном для проверки полноты нашего индексатора и, возможно, живым режимом после MVP.

Источник — [[F01-05 Разбор Unity и браузерных движков]]. Перед использованием живого режима — учесть условия Unity от 30.06.2026 (п. 17.2 ff/gg).
