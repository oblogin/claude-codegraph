# F-14 Глобальная база знаний

> **Что:** личная база разработчика с проверенными рецептами и уроками для всех его проектов, с возможностью подключать и сливать базы коллег.
> **Зачем:** если команда долго билась, например, над скриптом запуска игры на Unity и нашла решение, агент в другом проекте с нуля сразу находит и применяет его.
> **Готово, когда:** урок, записанный в одном проекте и поднятый в глобальные знания, агент в другом проекте находит по похожей задаче без подсказки человека.

## Входит

- Три уровня памяти:

  | Уровень | Где | Кто видит |
  |---|---|---|
  | Журнал работы | локально | только я |
  | Знания проекта | git репозитория проекта | команда проекта |
  | **Глобальная база** | локально у разработчика, не синхронизируется | все проекты разработчика |

- Запись — обобщённый рецепт, а не история проекта: задача, решение, условия применимости (движок и версия, ОС, язык), что пробовали и не сработало, источник (из какого проекта, коммит, дата), статус проверки.
- Метки технологий (`unity`, `go`, `rust`, `webgl`, `ci`…); плагин сам определяет стек проекта (например, Unity по `ProjectSettings/`) и ищет глобальные знания с подходящими метками.
- Подъём из знаний проекта в глобальные — только явным действием: агент предлагает «похоже на общий рецепт», человек или агент подтверждает, запись обобщается (убираются пути и имена проекта).
- Поиск по двум уровням сразу, в выдаче видно, откуда запись.
- Подключаемые базы: базу коллеги кладут рядом, поиск идёт по всем, в выдаче видно происхождение; команда слияния в свою базу (дубли, конфликты, происхождение) и команда выгрузки выбранных записей для передачи.
- Проверенный рецепт можно превратить в скилл (например, в маркетплейсе `claude-skills`).

## Не входит

- Публичная общая база для сообщества — после [[F-13 Публикация для сообщества]], если понадобится.
