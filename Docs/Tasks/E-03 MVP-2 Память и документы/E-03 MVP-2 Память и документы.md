# E-03 MVP-2 Память и документы

> **Что:** агент помнит опыт прошлых сессий и решения команды, а документы связаны с кодом в одном графе.
> **Зачем:** агент не повторяет отвергнутые подходы и знает, почему сделано именно так.
> **Готово, когда:** решение, записанное в одной сессии, находится агентом в другой сессии у другого участника команды после обычного `git pull`.

## Цель

Два уровня памяти и документы:

- **журнал работы** — автоматически записанные наблюдения из сессий, личные, локальные, не в git;
- **знания проекта** — решения, тупики, правила; отбираются из журнала, хранятся в git как Markdown и сливаются без боли;
- **глобальные знания команды** — проверенные рецепты и уроки, общие для всех проектов, в отдельном git-репозитории;
- **документы** — Markdown и PDF в том же графе, что и код, с пометкой, какие связи прочитаны напрямую, а какие выведены моделью.

Встроенную память Claude Code и ADR/журналы `claude-tasks` дополняем, а не дублируем.
