# F01-07 Локальные модели для простых задач

> **Что:** выяснить, какие простые задачи системы можно отдать локальным моделям и чем их запускать; начать с того, как это устроено в OpenWhispr.
> **Зачем:** сжатие журнала, классификация, обобщение рецептов и разбор PDF без облака и без расхода подписки пользователя.
> **Готово, когда:** есть ADR с выбором задач для локальных моделей, способа запуска и минимальных требований к железу.

## Критерии готовности

- [x] Разобрано, как OpenWhispr (`OpenWhispr/openwhispr`) использует локальные модели: какие модели, чем запускает, как скачивает и обновляет, как работает под Windows, как переключается между локальным и облачным режимом
- [x] Составлен список наших задач-кандидатов (сжатие наблюдений, классификация, поиск дублей по смыслу, обобщение рецептов для глобальных знаний, описания модулей, извлечение из PDF, голосовые заметки) с оценкой, справится ли маленькая модель
- [x] Сравнены способы запуска: llama.cpp, Ollama, LM Studio, ONNX Runtime, встроенный бинарник — по установке, Windows, GPU и CPU, размеру
- [x] Сравнены 3–5 маленьких моделей (например, Qwen, Gemma, Phi, Llama) по качеству на русском и английском, размеру, лицензии
- [x] Решено, что обязательно, а что по желанию: система должна работать и без локальной модели
- [x] Решение записано в ADR (`Adr/`), impl-задача может стартовать без повторного исследования

## Детали

Предложение пользователя 2026-09-29: посмотреть в сторону OpenWhispr, который использует локальные модели для простых задач вроде обработки голосовых сообщений.

Связь с ADR-001: там сжатие журнала «по умолчанию работает без модели», а описания модулей моделью в MVP не делаются. Локальная модель может снять эти ограничения без облака. Учесть отчёт `Docs/Research/02-memory-systems.md` (claude-mem тратит подписку — так не делаем).

  - Отдаём локальной модели (модуль по желанию, выключен по умолчанию): классификацию наблюдений, фоновое сжатие журнала, однострочные описания модулей (после MVP), смысловой разбор PDF, поиск дублей по смыслу (только если F-02 покажет пользу).

  - Правило «работает без модели» остаётся; модель не вызывается внутри хука; ответ помечается `source: model` и не становится действием.
  - Запуск: `llama-server` на 127.0.0.1 с API как у OpenAI, скачивается по команде (Windows: 17,3 МБ CPU, 38,9 МБ Vulkan) или адрес своего Ollama / LM Studio. Модель по умолчанию — Qwen3.5-4B Q4_K_M (≈3 ГБ, Apache-2.0).
  - Минимум для включения: x64 с AVX2, 16 ГБ памяти, 4 ГБ диска; комфортно — видеокарта 6+ ГБ.
  - Не измерено: скорость и качество на наших журналах и ноутбуках — допущения Л1–Л8 в ADR, первая impl-задача начинается с замера на 30–50 примерах. Открыт вопрос о сборках llama.cpp (Л3) и железе команды (Л8).
