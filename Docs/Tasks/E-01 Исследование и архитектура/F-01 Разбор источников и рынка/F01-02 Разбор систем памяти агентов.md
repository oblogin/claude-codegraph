## Детали

Источники:
- agentmemory — https://www.agent-memory.dev/ (npm `@agentmemory/agentmemory`, Apache-2.0)
- claude-mem — https://docs.claude-mem.ai/ (репозиторий `thedotmack/claude-mem`)
- OpenViking — https://openviking.ai/ (репозиторий `volcengine/OpenViking`); облачный вариант Volcengine для нас не подходит, смотреть только развёртывание у себя

Особое внимание:
- уровни L0/L1/L2 и поиск со сужением до папки в OpenViking;
- `<private>`, ссылки на наблюдения по ID и автоматические `CLAUDE.md` в папках у claude-mem;
- замена версий, `similarTo`, импорт логов сессий Claude Code (JSONL) у agentmemory;
- бенчмарки (LongMemEval, LoCoMo) — про память о переписке, а не про код: отметить это.
- Встроенная память Claude Code — как с ней сочетаются эти системы.

Структура отчёта для каждого решения: что это и для чего; как устроено на самом деле (со ссылками на файлы в исходниках); механизмы, полезные для наших слоёв (карта, последствия правок, журнал работы, знания проекта, документы, проверка); можно ли взять код (лицензия, язык, насколько отделяется); слабые места; вердикт — «взять код», «взять идею» или «не брать». В конце — сводная таблица приёмов.
