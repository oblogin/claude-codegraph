# F03-03 Хранение индекса и знаний

> **Что:** решить, где и в каком формате хранятся индекс кода, журнал работы и знания проекта.
> **Зачем:** индекс восстанавливается автоматически, а знания делятся через git и не конфликтуют при слиянии.
> **Готово, когда:** есть ADR с форматом и расположением каждого типа данных.

## Критерии готовности

- [ ] Индекс: формат, место (в `.gitignore`), инкрементальное обновление
- [ ] Журнал работы: личное локальное хранение, приватность
- [ ] Знания: Markdown в git, структура, привязка к символам, как избегать конфликтов слияния
- [ ] Глобальная база разработчика ([[F-14 Глобальная база знаний]]): личная, без синхронизации; подключение баз коллег, слияние и выгрузка; формат рецепта, метки технологий, подъём из знаний проекта
- [ ] Формат знаний выдерживает десятки тысяч записей: сравнены подходы (файл на запись, страницы по темам, SQLite, версионируемые БД и др.), решено, как знания устаревают, дополняются и правятся — решение обсуждено с пользователем
- [ ] Как читаем ADR и журналы `claude-tasks`
- [ ] Решение записано в ADR (`Adr/`), impl-задача может стартовать без повторного исследования
