# F03-03 Хранение индекса и знаний

> **Что:** решить, где и в каком формате хранятся индекс кода, журнал работы и знания проекта.
> **Зачем:** индекс восстанавливается автоматически, а знания делятся через git и не конфликтуют при слиянии.
> **Готово, когда:** есть ADR с форматом и расположением каждого типа данных.

## Критерии готовности

- [x] Индекс: формат, место (в `.gitignore`), инкрементальное обновление
- [x] Журнал работы: личное локальное хранение, приватность
- [x] Знания: Markdown в git, структура, привязка к символам, как избегать конфликтов слияния
- [x] Глобальная база разработчика ([[F-14 Глобальная база знаний]]): личная, без синхронизации; подключение баз коллег, слияние и выгрузка; формат рецепта, метки технологий, подъём из знаний проекта
- [x] Формат знаний выдерживает десятки тысяч записей: сравнены подходы (файл на запись, страницы по темам, SQLite, версионируемые БД и др.), решено, как знания устаревают, дополняются и правятся — решение обсуждено с пользователем
- [x] Как читаем ADR и журналы `claude-tasks`
- [x] Решение записано в ADR (`Adr/`), impl-задача может стартовать без повторного исследования
