# F03-04 Интерфейс для агента

> **Что:** определить, что агент получает сам через хуки, а что запрашивает инструментами MCP или скиллами.
> **Зачем:** максимум пользы при минимуме расхода контекста.
> **Готово, когда:** есть ADR со списком 5–8 инструментов, хуков и скиллов с описанием каждого.

## Критерии готовности

- [ ] Список инструментов MCP (цель 5–8) с входом и выходом
- [ ] Хуки: начало сессии, перед и после правки, конец сессии — что делает каждый
- [ ] Скиллы и команды плагина
- [ ] Оценён расход контекста на описания инструментов
- [ ] Решение записано в ADR (`Adr/`), impl-задача может стартовать без повторного исследования

## Детали

Вход — ADR из [[F01-06 Что берём из разобранных решений]].

## Проверка

1. ADR отвечает на все вопросы из критериев; зависимую impl-задачу можно делать, не возвращаясь к исследованию.
