# F-03 Архитектура системы

> **Что:** решения по ядру, языку, хранению и интерфейсу для агента.
> **Зачем:** реализация MVP-1 начинается без повторного исследования.

## Входит

- Своё ядро или готовый движок (Graft, CodeGraph, agentmemory и др.).
- Язык ядра и способ поставки плагина.

- Интерфейс: инструменты MCP (цель 5–8), хуки, скиллы.
