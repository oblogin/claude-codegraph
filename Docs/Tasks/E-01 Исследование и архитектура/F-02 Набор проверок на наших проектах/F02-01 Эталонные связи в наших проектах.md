# F02-01 Эталонные связи в наших проектах

> **Что:** выбрать 2–4 наших проекта и выписать 10–20 известных связей и несколько типовых задач с ожидаемым результатом.
> **Зачем:** это эталон, по которому меряем карту кода и последствия правок.
> **Готово, когда:** в `Bench/cases/` лежат описания эталонов, по каждому языку стека есть хотя бы две связи.

## Критерии готовности

- [ ] Выбраны проекты: Unity (C#), браузерная игра (JS/TS), сервер на Go, по возможности расширение на Rust
- [ ] По каждому проекту — связи «символ → все его потребители», включая непрямые вызовы, события, связи скрипт ↔ префаб в Unity
- [ ] Несколько задач «изменить X — что должно быть затронуто»
- [ ] Формат эталона описан и одинаков для всех проектов

## Детали

Нужны проекты от пользователя: пути или репозитории. Эталон составляет человек, знающий проект, или агент с последующей проверкой человеком. Пока проектов нет — задача в `draft`.

## Проверка

1. Открыть `Bench/cases/`: у каждого эталона указаны проект, символ, ожидаемые потребители.
