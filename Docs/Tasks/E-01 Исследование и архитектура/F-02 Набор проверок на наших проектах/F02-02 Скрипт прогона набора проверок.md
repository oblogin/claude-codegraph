# F02-02 Скрипт прогона набора проверок

> **Что:** скрипт, который прогоняет систему (или любой сравниваемый инструмент) по эталонам и считает полноту и расход контекста.
> **Зачем:** сравнивать варианты и видеть прогресс цифрами.
> **Готово, когда:** одна команда выдаёт отчёт с полнотой по каждому эталону и итогом.

## Критерии готовности

- [ ] Скрипт читает эталоны из `Bench/cases/`
- [ ] Можно подключить разные инструменты через адаптер (наша система, Graft, CodeGraph, простой grep как базовая линия)
- [ ] Отчёт: полнота, лишние находки, объём выданного контекста
- [ ] Базовая линия (grep) прогнана и записана

## Детали

Язык скрипта — по решению [[F03-02 Язык ядра и способ поставки]], но может стартовать раньше на любом удобном.

## Проверка

1. Запустить скрипт на эталонах, получить отчёт с базовой линией.
