# F02-02 Скрипт прогона набора проверок

> **Что:** скрипт, который прогоняет систему (или любой сравниваемый инструмент) по эталонам и считает полноту и расход контекста.
> **Зачем:** сравнивать варианты и видеть прогресс цифрами.
> **Готово, когда:** одна команда выдаёт отчёт с полнотой по каждому эталону и итогом.

## Критерии готовности

- [ ] Скрипт читает эталоны из `Bench/cases/`
- [ ] Можно подключить разные инструменты через адаптер (наша система, Graft, CodeGraph, простой grep как базовая линия)
- [ ] Отчёт: полнота, лишние находки, объём выданного контекста
- [ ] Базовая линия (grep) прогнана и записана
- [ ] Раннер читает и эталоны `Bench/cases/`, и синтетику `Tests/fixtures/*/*/expected.yaml` (поток документов); адаптер `to_bench()` переводит граф ADR-006 в словарь Bench по таблице «Соответствие модели графа» в `Bench/README.md`
- [ ] Пороги полноты и точности по базам — `Tests/thresholds.toml` (ADR-006 §12); раннер работает как `cargo test`
- [ ] Проверка эталонов: файл существует, строка в пределах, текст строки совпадает — и режим пересчёта номеров строк после правки базы

## Детали

Раннер — крейт воркспейса на Rust (ADR-004, крейт testkit из ADR-006). Основа валидатора эталонов уже была написана исполнителем F02-01 на Go во временной папке — переписать в Rust.

## Проверка

1. Запустить скрипт на эталонах, получить отчёт с базовой линией.
