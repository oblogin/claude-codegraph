# F-12 Связи между языками

> **Что:** связи клиент ↔ сервер на Go и код ↔ Rust-расширения через контракты (protobuf, OpenAPI, FFI, WASM).
> **Зачем:** правка на сервере показывает, что затронуто на клиенте, и наоборот.
> **Готово, когда:** для эталонного эндпоинта граф связывает обработчик на Go и вызовы на клиенте.

## Входит

- Контракты API и сообщений.
- FFI и WASM для Rust.

## Не входит

- Связи по строковым совпадениям без контракта.
