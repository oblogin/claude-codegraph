# F-09 Проверка изменений

> **Что:** проверка правок перед слиянием в три ступени: механическая, LLM-ревью в отдельном контексте, второе мнение для рискованного.
> **Зачем:** ошибки ловятся до слияния.
> **Готово, когда:** на наборе изменений с известными ошибками проверка находит их с приемлемой долей ложных замечаний.

## Входит

- Механическая ступень: сборка, линтер, затронутые тесты из [[F-05 Последствия правок]].
- LLM-ревью в отдельном контексте с картой влияния и знаниями проекта.
- Второе мнение другой модели для рискованных изменений.
- Проверочные команды не показываются агенту, который пишет код.

## Не входит

- Выполнение кода в песочнице (как TREX в Greptile) — позже, если понадобится.
