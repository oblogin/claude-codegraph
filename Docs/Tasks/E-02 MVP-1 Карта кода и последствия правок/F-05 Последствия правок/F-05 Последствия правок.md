# F-05 Последствия правок

> **Что:** перед правкой агент видит вызывающих, связанные тесты и историю; после правки — предупреждение о затронутом.
> **Зачем:** агент реже ломает то, чего не видит.
> **Готово, когда:** на задачах из набора проверок агент находит всех эталонных потребителей изменяемого кода.

## Входит

- Контекст перед правкой (по образцу `get_edit_context` в CodeGraph).
- Хук после правки с предупреждением о зависимостях (по образцу Graft).
- Поиск связанных тестов.

## Не входит

- Ревью логики изменений — [[F-09 Проверка изменений]].
