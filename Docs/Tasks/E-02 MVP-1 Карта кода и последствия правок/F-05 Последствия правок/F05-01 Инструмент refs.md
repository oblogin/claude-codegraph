# F05-01 Инструмент refs

> **Что:** инструмент `refs`: кто использует X и что использует X, по видам связей, неоднозначные — по запросу.
> **Зачем:** основа ответа «кто зависит от кода».
> **Готово, когда:** на эталонах F02-01 `refs` находит обязательные связи и не выдаёт запрещённые.

## Критерии готовности

- [ ] Группы по видам связей из ADR-003
- [ ] Постраничная выдача и бюджет
- [ ] Неоднозначные — только по флагу
- [ ] Проверка на эталонах через тест-раннер F02-02
