# F05-03 Хук поиска grep

> **Что:** хук PreToolUse на Grep: если искомое имя есть в графе — определения и ссылки из ассетов, которых grep не видит.
> **Зачем:** агент по привычке ищет grep-ом; хук добавляет недостающее.
> **Готово, когда:** хук укладывается в 100 мс и срабатывает раз на имя за сессию.

## Критерии готовности

- [ ] Вставка не больше 400 символов
- [ ] Раз на имя за сессию
- [ ] Замер времени на Windows
