# F-04 Карта кода

> **Что:** сжатая карта проекта для агента: модули, символы, связи, уровни детализации L0 → L1 → L2.
> **Зачем:** агент не изучает проект заново в каждой сессии.
> **Готово, когда:** на наборе проверок карта находит эталонные связи для C#, JS/TS, Go и Rust.

## Входит

- Разбор C#, JS/TS, Go, Rust (скорее всего tree-sitter, опционально LSP).
- Уровни детализации: суть модуля, API без тел функций, исходник.
- Поиск со сужением до модуля или папки.
- Обновление карты после правок.

## Не входит

- C++ и Unreal — [[F-11 Поддержка Unreal]].
- Смысловые описания моделью — решим в архитектуре, нужны ли в MVP.
