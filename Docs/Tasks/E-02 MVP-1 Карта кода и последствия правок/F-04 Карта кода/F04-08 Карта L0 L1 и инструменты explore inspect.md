# F04-08 Карта L0 L1 и инструменты explore inspect

> **Что:** карта проекта по уровням с бюджетом токенов (ранжирование как в Aider repo-map) и инструменты `explore`, `inspect` по ADR-003.
> **Зачем:** агент не изучает проект с нуля в каждой сессии.
> **Готово, когда:** в сессии Claude Code `explore` без запроса отдаёт карту L0 в пределах бюджета, `inspect` — символ с соседями.

## Критерии готовности

- [ ] Ранжирование символов под бюджет токенов
- [ ] `explore`: карта L0 и ответ на вопрос «где/что»
- [ ] `inspect`: символ, файл, ассет Unity, документ
- [ ] Вставка SessionStart с картой L0 не больше 2000 символов
