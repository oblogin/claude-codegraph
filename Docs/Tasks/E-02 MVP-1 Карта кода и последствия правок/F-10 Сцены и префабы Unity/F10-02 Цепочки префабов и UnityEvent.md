# F10-02 Цепочки префабов и UnityEvent

> **Что:** вложенные префабы и варианты с удалёнными и добавленными компонентами, UnityEvent → метод, сериализованные поля, сообщения движка.
> **Зачем:** это связи, которых нет ни в одном готовом инструменте.
> **Готово, когда:** на базе Unity и на открытом Unity-проекте эталоны «где висит компонент» и «кто вызывает метод через UnityEvent» проходят.

## Критерии готовности

- [ ] `PrefabInstance.m_SourcePrefab`, варианты, `m_RemovedComponents` и `m_AddedComponents`
- [ ] UnityEvent по `m_Mode` → ребро на метод C#
- [ ] Сериализованные поля: ключ в YAML ↔ поле класса
- [ ] Where-used компонента вычисляется запросом по ADR-006
- [ ] Проверка на эталонах
