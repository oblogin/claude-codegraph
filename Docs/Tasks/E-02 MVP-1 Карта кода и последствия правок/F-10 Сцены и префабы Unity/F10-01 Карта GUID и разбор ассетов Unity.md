# F10-01 Карта GUID и разбор ассетов Unity

> **Что:** модуль Unity: карта GUID из `.meta`, потоковый разбор сцен, префабов и ассетов по заголовкам документов, `m_Script`, ссылки на ассеты; fileID строкой.
> **Зачем:** без этого граф не видит, где висят скрипты.
> **Готово, когда:** на базе Unity из F02-03 скрипты привязаны к объектам сцен и префабов.

## Критерии готовности

- [ ] Карта `guid → путь, тип` из `Assets/`, `Packages/`, `Library/PackageCache/` (если есть)
- [ ] Потоковый разбор документов `--- !u!N &ID`
- [ ] Рёбра `m_Script`, ссылок на ассеты, Addressables
- [ ] Проверка на базе F02-03
