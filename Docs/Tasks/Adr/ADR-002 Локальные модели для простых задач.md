# ADR-002 Локальные модели для простых задач

> **Решение:** локальная модель — необязательный и по умолчанию выключенный модуль. Пользователь выбирает Ollama или LM Studio; плагин по клику ставит выбранное, запускает сервер и скачивает модель из предложенного списка (по умолчанию Qwen3.5-4B). Модели отдаём классификацию, фоновое сжатие журнала, описания модулей и разбор PDF, а обобщение рецептов, фильтр секретов и граф кода — нет.
> **Почему:** так «умные» операции памяти работают без облака и без расхода подписки, а на слабом ноутбуке или без модели система работает так же, как по ADR-001. Этот путь OpenWhispr проверил под Windows, и он не зависит от языка ядра.
> **Следствия:** F-06, F-07, F-08 и F-14 проектируют каждую «умную» операцию с запасным путём без модели. F03-02 не поставляет нативных бинарников модели: их ставят Ollama или LM Studio. Первая impl-задача начинается с замера качества и скорости на наших журналах и ноутбуках.

## Контекст

**Проблема.** По ADR-001 (разделы 4, 5, 5а, 6) все «умные» операции памяти по умолчанию работают без модели. Сжатие журнала — синтетическое, описания модулей моделью в MVP не делаются, поиск дублей идёт по словам, PDF — только текст и имена. Без модели это работает, но слабо: у agentmemory без LLM сжатие почти бесполезно (отчёт 02). Облачная модель не подходит: код не должен уходить в чужие облака. Второй процесс Claude (как у claude-mem) тоже не подходит: он тратит подписку пользователя. Пользователь предложил посмотреть на локальные модели по примеру OpenWhispr.

**Ограничения.**
- Плагин Claude Code, установка одной командой, без демона, Docker и Python.
- Основная ОС команды — Windows. Обычный ноутбук разработчика, на котором рядом открыт редактор Unity.
- Язык ядра ещё не выбран ([[F03-02 Язык ядра и способ поставки]]).
- Архитектура — для сообщества: лицензии моделей и движков должны быть открытыми.

**Источник.** Отчёт `Docs/Research/07-local-models.md`: разбор исходников OpenWhispr (MIT, коммит `64ac554`), сравнение шести способов запуска и девяти моделей, задачи-кандидаты с оценкой задержки. Главное из OpenWhispr:
- каждая нативная модель живёт в отдельном процессе;
- `llama-server` закреплённой версии; сборка для CPU вшита, сборка с Vulkan скачивается по требованию, архив проверяется по sha256;
- модели скачиваются с Hugging Face по кнопке;
- откат Vulkan → CPU;
- контекст считается от бюджета памяти;
- после 5 минут простоя модель выгружается;
- на Windows путь к моделям только из ASCII;
- при сбое модели — мягкая деградация до результата без модели.

## Решение

### 1. Статус модуля

Локальная модель — **необязательный модуль, выключенный по умолчанию**. Каждая функция, которая им пользуется, имеет путь без модели и работает без него полностью. Облачные модели и второй процесс Claude для этих задач не используются. Это правило ADR-001 «по умолчанию без модели» уточняет, а не отменяет.

### 2. Какие задачи отдаём модели

| Задача | Модели | Условие | Без модели | Фича |
|---|---|---|---|---|
| Классификация наблюдения: тип, понятия, метки технологий, «похоже на общий рецепт» | **да** | JSON из закрытого списка значений | Правила по инструменту, исходу и стеку проекта | [[F-06 Журнал работы агента]], [[F-14 Глобальная база знаний]] |
| Сжатие журнала сессии в наблюдения | **да** | Только в фоне: по `SessionEnd` или лениво при следующем старте, короткоживущим процессом | Синтетическое сжатие (образец — agentmemory) + явные пометки агента | [[F-06 Журнал работы агента]] |
| Однострочные описания модулей и папок (L1) | **да, после MVP** | Лениво; пересчёт только при смене хэша L0; пометка `source: model` | L0/L1 без модели (ADR-001, раздел 1) | [[F-04 Карта кода]] |
| Смысловой проход по PDF: термины, упоминания, связи | **да** | По кускам, один раз на версию файла; рёбра только `INFERRED`/`AMBIGUOUS` | Текстовый слой, имена → граф, деление по заголовкам | [[F-08 Документы в графе]] |
| Поиск дублей по смыслу | **модель эмбеддингов, по желанию** | Только если [[F02-02 Скрипт прогона набора проверок]] покажет пользу над BM25 (К9, Д10); только подсказка, без автозамены | FTS5/BM25 + сходство слов | [[F-07 Знания проекта]], [[F-14 Глобальная база знаний]] |
| Обобщение рецепта для глобальных знаний | **нет** | Формулирует основной агент в текущей сессии по явной команде, человек подтверждает | Детерминированная обезличка путей, `origin` и имён проекта | [[F-14 Глобальная база знаний]] |
| Фильтр секретов и приватности | **нет, никогда** | — | Правила и регулярные выражения | [[F-06 Журнал работы агента]], [[F-07 Знания проекта]] |
| Рёбра графа кода, решения о последствиях правок | **нет** | — | Разбор кода | [[F-04 Карта кода]], [[F-05 Последствия правок]] |
| Голосовые заметки | **нет, вне плагина** | Для ввода голосом — диктовка ОС или OpenWhispr | — | — |

**Правила для всех задач модели.**
- Модель не вызывается синхронно в хуке. Хук ≤ 500 мс только пишет событие, а работа модели идёт через очередь.
- Ответ — JSON по схеме (`response_format` / `json_schema` у `llama-server`). Ответ проверяется; при ошибке — один повтор, затем результат без модели.
- Результат модели помечается `source: model`, моделью и её версией. Это недоверенный текст: в git он попадает только явным действием человека или агента.
- Вывод модели никогда не становится действием: не вызывает инструменты, не меняет граф, не коммитит.
- Фильтр приватности применяется до отправки текста модели.

### 3. Способ запуска

*Изменено 2026-09-29 по решению пользователя: вместо своего `llama-server` — выбор Ollama или LM Studio с установкой по клику.*

Интерфейс к модели один — **HTTP, совместимый с OpenAI** (`/v1/chat/completions` с `json_schema`, `/v1/embeddings`). Его дают и Ollama, и LM Studio, поэтому ядро не зависит от выбора и от своего языка.

**Команда включения модуля** (одна, по клику):
1. Показывает выбор: **Ollama** (открытый код, MIT, работает службой) или **LM Studio** (бесплатное приложение с интерфейсом, код закрыт). Если одно из них уже установлено — предлагает его.
2. Если выбранное не установлено — ставит по клику: на Windows через `winget`, на macOS через `brew`, иначе — ссылка на официальный установщик. Показывает размер загрузки до начала.
3. Запускает сервер на `127.0.0.1` (Ollama — служба на `:11434`; LM Studio — `lms server start`, `:1234`) и проверяет здоровье.
4. Показывает список моделей (раздел 4) с размером и требованиями, отмечает рекомендуемую для этой машины по ОЗУ и видеопамяти; скачивает выбранную (`ollama pull` или `lms get`).
5. Делает пробный запрос с JSON-схемой и сообщает результат.

**Работа.**
- Модель загружается по требованию и выгружается после 5 минут простоя (`keep_alive` у Ollama, TTL у LM Studio).
- Thinking выключен; ответ — JSON по схеме, проверяется; при ошибке — один повтор, затем путь без модели.
- Тайм-ауты на запрос; если сервер не отвечает — путь без модели и одно предупреждение за сессию.
- Разрешены только `localhost`/`127.0.0.1`. Другой хост — только явной настройкой с предупреждением, что текст журнала и код уйдут с машины.
- Можно указать и любой другой совместимый сервер (`llama-server`, Foundry Local) адресом и именем модели — без установки по клику.

**Выключение** — командой плагина: модуль выключается, модели и программа остаются, удалить их можно штатно (`ollama rm`, удаление приложения). Телеметрии у плагина нет.

### 4. Модели

Список моделей — в конфиге плагина: для каждой — имя в каталоге Ollama и в каталоге LM Studio, размер и требования. Команда включения предлагает несколько моделей и отмечает рекомендуемую для машины; можно указать любую другую модель, уже скачанную в Ollama или LM Studio.

| Роль | Модель | Файл | Лицензия |
|---|---|---|---|
| **По умолчанию** | Qwen3.5-4B Q4_K_M | ~2,7–3,0 ГБ | Apache-2.0 |
| Лёгкая (8 ГБ ОЗУ, только классификация) | Qwen3.5-2B Q4_K_M | 1,4 ГБ | Apache-2.0 |
| Сильная (видеокарта ≥ 8 ГБ) | Qwen3.5-9B Q4_K_M | 5,9 ГБ | Apache-2.0 |
| Запасная линейка, если у Qwen3.5 провал на русском | Gemma 4 E4B (QAT q4_0) | 5,2 ГБ | Apache-2.0 |
| Эмбеддинги (только после замера на F-02) | Qwen3-Embedding-0.6B Q8_0 | 0,64 ГБ | Apache-2.0 |

Веса мы не распространяем: их скачивают Ollama или LM Studio по команде пользователя. В список попадают только модели с открытой лицензией.

### 5. Минимальные требования к железу

| Уровень | Железо | Модель | Что работает |
|---|---|---|---|
| 0 | любое | нет | всё, путями без модели |
| 1 | x64 с AVX2, 8 ГБ ОЗУ, 2 ГБ диска | Qwen3.5-2B | только классификация |
| **2 — минимум для включения модуля** | x64 с AVX2, **16 ГБ ОЗУ**, 4 ГБ диска | Qwen3.5-4B | классификация; сжатие сессии в фоне (минуты на CPU); описания модулей и PDF — медленно, по команде |
| 3 — комфортный | + видеокарта ≥ 6 ГБ с Vulkan или CUDA | Qwen3.5-4B, или 9B при ≥ 8 ГБ видеопамяти | всё из раздела 2, за секунды |

Команда включения проверяет ОЗУ и свободное место и предупреждает, если машина ниже уровня 2.

### 6. Что это меняет в плане

- [[F-06 Журнал работы агента]]: очередь фоновой обработки и отсоединённый процесс по `SessionEnd`; поле `source` у наблюдения; синтетическое сжатие остаётся основным путём.
- [[F-07 Знания проекта]] и [[F-14 Глобальная база знаний]]: подъём и обобщение делает основной агент по явной команде; модель только классифицирует и подсказывает похожие записи.
- [[F-08 Документы в графе]]: смысловой проход по PDF — необязательный слой поверх разбора без модели.
- [[F03-02 Язык ядра и способ поставки]]: нативных бинарников модели плагин не поставляет; нужна установка Ollama или LM Studio по клику (`winget`, `brew`), из ядра — HTTP-клиент и запуск внешних команд.
- [[F03-04 Интерфейс для агента]]: команда включения и выключения модуля; ответы инструментов показывают `source`.
- Модулю нужна отдельная impl-задача в MVP-2 (по решению лида). Она начинается с замера по допущениям Л1–Л6.

## Отвергнутые варианты

- **Облачная модель для этих задач** (API Anthropic, OpenAI и др.): код и журнал уходят в чужое облако, и это стоит денег. Исключение — основной агент в текущей сессии по явной команде пользователя.
- **Второй процесс Claude как «наблюдатель»** (claude-mem): тратит подписку пользователя без его явного действия (отчёт 02).
- **Локальная модель как обязательная часть**: ломает установку одной командой и работу на слабых ноутбуках; система должна работать без модели.
- **Свой управляемый `llama-server`** (первоначальный вариант этого ADR, по образцу OpenWhispr): пришлось бы самим следить за сборками llama.cpp под три ОС (последний релиз `v0.5.0` вышел без бинарников), видеокартами и откатами. Пользователь выбрал Ollama или LM Studio с установкой по клику — они это уже делают. Любой `llama-server` можно подключить адресом.
- **Встраивать LM Studio или Ollama в плагин**: плагин их не распространяет, а ставит официальным способом по выбору пользователя. Для сообщества важно: у LM Studio закрытый код и свои условия использования — это выбор пользователя, не зависимость плагина.
- **ONNX Runtime GenAI и Foundry Local как основа**: моделей в ONNX меньше и их надо конвертировать; конфликт `onnxruntime.dll` в System32 Windows 11 (урок OpenWhispr #2054); у Foundry Local закрытая среда выполнения и свой каталог моделей. Foundry Local можно подключить как внешний источник.
- **node-llama-cpp внутри процесса плагина**: привязывает решение к ядру на Node, хотя F03-02 ещё не решена; падение нативного кода роняет плагин; пакеты весят 30–370 МБ на вариант. Возможен только как замена источнику А, если ядро окажется на Node и замер покажет выгоду.
- **Вшивать бинарник или модель в плагин**: раздувает установку для всех, включая тех, кому модель не нужна. Скачиваем по команде.
- **Проверять модель только по размеру файла** (как OpenWhispr): не ловит подменённый или битый файл. У нас — sha256.
- **Крошечные модели (< 1B) и LFM2.5**: Qwen3.5-0.8B слишком слаба для структурированного вывода (MMLU-Pro 29,7). У LFM2.5 нет русского, а лицензия ограничивает компании с выручкой выше $10 млн.
- **Llama 3.2**: русского нет среди официальных языков; своя лицензия с обязательной надписью «Built with Llama».
- **Phi-4-mini по умолчанию**: MIT и русский в списке языков, но модель 2025-02 заметно слабее Qwen3.5-4B по карточкам. Можно указать вручную.
- **Обобщение рецептов для глобальных знаний локальной моделью без проверки**: ошибка в условиях применимости расходится по всем проектам команды.
- **Модель в хуке синхронно**: задержка в секундах и минутах на CPU нарушает правило «хук ≤ 500 мс».
- **Голосовые заметки в плагине**: это не задача плагина; для ввода голосом есть диктовка ОС и сам OpenWhispr.
